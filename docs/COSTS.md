# Скільки коштує тримати застосунок розгорнутим

Розрахунок для **10 днів**, регіон **us-west-2**, **платний план без кредитів** (ціни — публічні
тарифи AWS на кінець 2026 р.; перевіряй актуальні на сторінках pricing). «Always Free» — ліміти, що
діють завжди, незалежно від віку акаунта.

## Що розгорнуто і чи воно платне саме по собі

|---|---|---|---|

($3,6/міс кожна), WAF ($5+/міс), Secrets Manager, власні KMS-ключі ($1/міс). Lambda працюють поза VPC.

**Разом, простій 10 днів: ≈ $0,00–0,01** (у найгіршому разі для дашборда — ≈ $1).

## Якщо ти сам користуєшся сайтом і все перевіряєш

Припущення з запасом: 10 днів по ~2 000 запитів до API на день (реєстрація, меню, бронювання,
групове замовлення, сторінка власника, що оновлюється кожні 15 с, поки відкрита у видимій вкладці).

| Що | Обсяг за 10 днів | Вартість |
|---|---|---|
| API Gateway | ~20 000 запитів (+ CORS-запити браузера ≈ ×2) | ~40 000 × $3,50/млн ≈ **$0,14** |
| Lambda | 20 000 викликів, ~2 500 GB-с | у безкоштовних межах — **$0** |
| DynamoDB, Cognito, CloudFront, SQS | далеко в межах лімітів | **$0** |
| S3 (кожен «Deploy all» ≈ 200 файлів сайту + збірка backend) | 5 деплоїв | **≈ $0,01** |
| Логи CloudWatch | десятки MB | **$0** |

**Разом з ручним використанням: ≈ $0,15–0,20 за 10 днів.**

## Захист від несподіваних рахунків

1. **Ліміт запитів на API** (додає «Deploy all» на кроці *Limit API request rate*): 3 запити/с,
   короткий сплеск до 30. Запити понад ліміт отримують 429, **до Lambda не доходять і не
   оплачуються**. Найгірший випадок — бот 10 діб безперервно б'є в API на межі ліміту:
   3 × 86 400 × 10 ≈ 2,6 млн запитів ≈ **$9** за API Gateway + ≈ $0,3 за Lambda.
   Змінити: змінні репозиторію `API_RATE_LIMIT` / `API_BURST_LIMIT` (менше — дешевший найгірший
   випадок, але частіші помилки «429» при швидких кліках).
2. **Бюджет $5/міс** зі сповіщеннями на e-mail (80% фактичних витрат і 100% прогнозу) — додай змінну
   `ALERT_EMAILS` = `["твій@email"]` і підтвердь підписку з листа AWS.
3. **Перевірка**: Billing and Cost Management → **Bills** (оновлюється кілька разів на день),
   **Cost Explorer** (з затримкою до доби).
4. **Наприкінці**: Actions → **Destroy all** (ввести `destroy`) — у AWS лишаються тільки 2 бакети
   bootstrap і роль для GitHub (центи за рік). Щоб прибрати і їх — `terraform destroy` у
   `infra/bootstrap` (спершу очисти бакет зі станом: S3 → `restaurant-terraform-state-…` → Empty).
